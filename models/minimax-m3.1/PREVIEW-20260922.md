## 1. Model Architecture Changes
- Full Attention in the first three layers is replaced with Sparse Attention.
- NVFP4-related: sparse (indexer, main) `q8kv8 -> q8kv4`; MoE routed experts `MXFP8 -> NVFP4`.

### 1.1 Attention Q8KV4 (indexer + sparse main branch)
- **Q8**: q (incl. indexer q) from q_proj in BF16, then cast to FP8 E4M3.
- **KV4**: k, v (incl. indexer k) from k_proj / v_proj in BF16, then quantized to E2M1.

KV NVFP4 procedure, per head of 128 BF16 values: split into 8 blocks of 16 consecutive values; per block amax; per block
`scale = E4M3(amax / 6)` clamped to `[1/512, 448]`; divide by the block scale and map to 4-bit E2M1.
```python
FP4_MAX = 6.0
amax     = max(|x| over 16 elems);  amax = max(amax, 1e-12)
scale    = float(E4M3(amax / 6.0)); scale = min(448, max(scale, 1/512))
x_scaled = x / scale
mag      = ladder(min(|x_scaled|, 6))                 # RNE ladder
code     = (sign_bit if mag != 0 else 0) | mag        # 4-bit E2M1 CODE
```
Key constraints: `tensor_scale = 1` (no outer/global scale); round-half-to-even (ladder thresholds asymmetric, NOT hardware
round-half-up); zero special case — `mag == 0` forces positive-zero `0000`, never `1000` (-0).

RNE ladder, `a = min(|x_scaled|, 6)`:
| condition | mag | value |
|---|---:|---:|
| `a > 5.0` | 7 | 6.0 |
| `a >= 3.5` | 6 | 4.0 |
| `a > 2.5` | 5 | 3.0 |
| `a >= 1.75` | 4 | 2.0 |
| `a > 1.25` | 3 | 1.5 |
| `a >= 0.75` | 2 | 1.0 |
| `a > 0.25` | 1 | 0.5 |
| else | 0 | 0.0 |

### 1.2 MoE W4A4_NVFP4 (routed experts only; shared expert excluded)
**W4:** per expert, FC1 (w1, w3) share one `G_w = weight_global_scale`; FC2 (w2) uses another. `w_norm = w * G_w`;
reconstruct as `fp4_value * weight_scale / G_w`.

**FC1 A4 — dynamic row scale + block scale:** `row_amax = max(|x|)`, `S_enc = 2688 / row_amax`; store
`row_scale = BF16(row_amax / 2688)`, `x_norm = BF16(x * S_enc)`; per 16 elems `activation_scale = UE4M3(block_amax / 6)`;
`fp4_code = E2M1(x_norm / activation_scale)`; use activation_scale in the GEMM; after FC1, before the activation function,
multiply each row by `row_scale`.

**FC2 A4 — fixed outer scale + block scale:** all rows `S_enc = 16`; per 16 elems
`activation_scale = UE4M3(block_amax * (1/6) * S_enc)`; `fp4_code = E2M1(z / (activation_scale / S_enc))`; use
activation_scale in the GEMM and multiply the GEMM output by `1/S_enc`.
